# Viva Questions — Used Car Price Prediction

1. **What is the objective?** Estimate a used car's resale price from its specifications.
2. **Which ML task is used?** Supervised regression because the target selling price is continuous.
3. **Why Random Forest?** It combines many decision trees and can model nonlinear relationships.
4. **What is preprocessing?** Transforming raw data into a form suitable for model training.
5. **Why one-hot encoding?** To represent categorical labels numerically without imposing an artificial order.
6. **Why imputation?** To handle missing feature values without discarding every incomplete row.
7. **What is MAE?** Mean absolute difference between actual and predicted prices.
8. **What is RMSE?** Square root of mean squared error; it penalizes large errors more strongly.
9. **What is R²?** A measure of variance explained by the model relative to a mean baseline.
10. **Why split train and test data?** To estimate performance on unseen examples.
11. **What is overfitting?** When a model learns training-specific patterns that do not generalize.
12. **What is an API?** A defined interface that lets software components communicate.
13. **Why FastAPI?** It provides request validation, automatic API documentation and a convenient Python serving layer.
14. **Why React?** It supports reusable UI components and interactive state.
15. **What is data leakage?** When information unavailable at prediction time influences training or evaluation.
16. **Why is synthetic data a limitation?** It does not reflect real market distributions or true pricing behaviour.
17. **What would improve the model?** Larger representative data, richer vehicle attributes, careful validation and model comparison.
18. **Is the price guaranteed?** No. It is an indicative model estimate, not a dealer quote.
